FAQ

    
想知道的，都在这里。

    

      
Happy 是什么？
Happy 是一个 AI API 网关，把多家主流大模型统一成一个接口。你只需一个 Key，就能调用 Claude、GPT、Gemini 等模型，并享受智能路由与稳定加速。

      
如何接入？需要改代码吗？
几乎不需要。将 SDK 的 Base URL 替换为 Happy 提供的地址，API Key 替换为控制台生成的 Key 即可，兼容 OpenAI 与 Anthropic 原生协议。

      
如何计费？
按实际 Token 用量计费，不同分组有不同倍率，所有明细都可以在控制台随时查看。余额不足时会提前温柔提醒你。

      
服务稳定吗？
我们对每条渠道进行分钟级健康探测，异常时自动切换。你可以在「渠道监控」页面实时查看各渠道状态。

      
邀请返利怎么参与？
登录后进入「邀请返利」页面获取专属链接，好友通过你的链接注册并使用，你将获得相应返利额度。
